Get Ready to Solve an IDrive Issue

Use a clear checklist to identify the issue, protect your data and prepare useful details before requesting account-specific assistance.

Prepare the details

Write down the device type, operating system, IDrive application version, approximate time the issue began and the exact error wording. Include the steps that reproduce the issue, but do not include passwords, verification codes or private file contents.

Protect existing backups

Do not delete backup folders, reset the account or uninstall software as an early troubleshooting step. First confirm that you can access the correct account and understand where existing backup data is stored. Keep separate copies of irreplaceable files.

Check common causes

Review internet connectivity, available disk space, device permissions, application updates, selected folders, exclusions and active backup jobs. Test one change at a time so that you can identify which step affects the result.

Use verified support routes

For account-specific, billing or product questions, open the IDrive website or application independently and use its current Help or Support options. Verify the web address before signing in. This website is an independent educational resource and does not provide IDrive account access.
